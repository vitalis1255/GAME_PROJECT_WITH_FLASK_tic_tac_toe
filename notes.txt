et emptyCells = board.map((val,idx)=> (val === "" ? idx : null)).filter((val) => val !== null); This line of code identifies all the empty cells in the board array and stores their indices in emptyCells.
Explanation:
board.map((val, idx) => ...): Loops through each element in the board array. val is the cell's value, while idx is its index.

val === "" ? idx : null: Uses the ternary operator. If the cell is empty (""), it returns its index (idx); otherwise, it returns null.

.filter((val) => val !== null): Removes all null values, leaving only the indices of empty cells.
